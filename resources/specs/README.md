# specs

Landing dir for technical specs generated by the `spec-construction` skill
(`.claude/skills/spec-construction/SKILL.md`).

Naming: `YYYY-MM-DD-<kebab-slug>.md`.

Invoke via Claude Code:

```
/spec-construction   or   "write a spec for <feature>"
```

Diagrams are embedded as PlantUML fenced blocks. Render locally with any
PlantUML-aware markdown viewer, or paste into `plantuml.com/plantuml/`.
